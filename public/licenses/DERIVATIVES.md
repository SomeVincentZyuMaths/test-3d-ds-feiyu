## 三位结构改版

`avatars/gpt.vrm`、`avatars/gemini.vrm`、`avatars/claude.vrm` 基于上述作者的
`DeepSeek-chan.blend`，在本项目中通过 Blender 脚本重新制作。
它们及对应的 `models/nike-derived/*.blend` 均按 **CC BY-NC-SA 4.0** 分享。
需要署名、标明修改、非商业使用，并以相同许可分享衍生作品。

共同保留：原版长身比例、脸部造型与表情形态键、人体骨骼、皮肤、手部、腿部及部分刘海。
共同修改：删除原女仆裙、鲸鱼尾巴和背部蝴蝶结；重建衣装、长发和配件；调整发色、虹膜与鞋袜贴图。

| 文件         | 本项目的主要修改                                             |
| ------------ | ------------------------------------------------------------ |
| `gpt.vrm`    | 银白长发、弯曲双角、淡紫膜翼、白色分层长裙、带鳞纹的独立龙尾 |
| `gemini.vrm` | 蓝紫侧发与发髻、猫耳、星饰、紫色短裙、弯曲大尾巴             |
| `claude.vrm` | 铜橙长发、太阳花与黑缎带、白棕长裙、带页边和封面装饰的书     |
